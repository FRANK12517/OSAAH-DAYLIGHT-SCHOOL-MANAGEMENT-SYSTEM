USER GUIDE

Using the school management system

Navigation

Use Dashboard Overview for executive summaries. Open a red navigation group heading to reveal its authorized modules. The current module is highlighted automatically.

Access and security

Your menu is generated from your role and permissions. If a required module is unavailable, contact the school administrator. Always use Logout when you finish on a shared device.

Mobile use

Use the Menu button to open the navigation drawer. Selecting a destination closes the drawer and opens that module.
